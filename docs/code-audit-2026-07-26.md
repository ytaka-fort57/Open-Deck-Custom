# Open-Deck Custom 残対応監査

監査日: 2026-07-26  
対象: `custom` ブランチの作業ツリー  
範囲: `docs/` と `docs/archive/` の過去監査・課題文書を現行コードと照合し、未対応、意図的保留、外部確認を再分類

## 結論

過去文書に残っていたコード対応のうち、カラム内の戻るボタン、動画variant選択、文章校正observerの破棄を実装した。対応中に、文章校正のエディタobserver本体が保持されていないことに加え、observer callbackが共有変数を参照し、別エディタへフォーカスした後に誤った要素を見る可能性を確認したため同時に修正した。

現時点で高優先度のコード残件はない。残る項目は実ブラウザー／GitHub上の外部確認、利用予定のないカラム型、fixture整備とデータ移行を伴う低優先度リファクタである。

## 今回の対応

| 項目 | 状況 | 対応 |
| --- | --- | --- |
| Xの戻るボタン | 修正済み | capture段階で対象ボタンを検出し、そのiframeの独自URL履歴がある場合だけ標準処理を置換 |
| 動画variant選択（旧L-2） | 修正済み | HTTPS候補を検証し、MP4の最高bitrateを表示・ダウンロードで共通利用。MP4が無い場合のみ安全な代替候補を利用 |
| 文章校正observer（N-7） | 修正済み | column共通disposerを追加し、メインobserver、各エディタobserver、focus listenerを列破棄時に解除 |
| 新発見: editor参照の競合 | 修正済み | observerごとに監視対象を固定し、別エディタへのfocus移動で参照先が変わらないよう修正 |
| 列破棄処理 | 修正済み | 列閉じ、セカンドラック解除、プロファイル切替、deck再構築を共通disposerへ接続 |

## 残対応

| 優先度 | 項目 | 判断 |
| --- | --- | --- |
| 中 | Firefox Manifest V2 実機確認 | Firefox本体はローカルに存在するが、ログイン状態を含む操作確認が必要。自動検証ではZIP構造・manifest・参照ファイルまで確認する |
| 中 | `sync-upstream.yml` 初回dispatch | Issue作成・更新を伴う外部操作。現在の変更をGitHubへ反映した後、手動dispatchで確認する |
| 中・保留 | `misskey` / `bsky` | 利用予定なし。描画不能なままcodecだけ受理すると設定が黙って消えるため、描画・保存・import・移行testを一括実装する時まで保留 |
| 低 | `content.js` DOM実行テスト | 責務をcontroller／純粋関数へ分ける際、文字列検査を段階的に実行テストへ置換する |
| 低・設計保留 | タブ状態の安定ID化（旧R-2） | 現行操作は位置remapで保護済み。全プロファイル移行と旧データ互換、実ブラウザーfixtureが揃ってから行う |

## 過去文書から再確認した判断

- 本家更新は頻度が低い間、直接mergeではなく差分を読み、customの現在構造へ意味単位で再実装する。競合回避だけを理由に有益なリファクタを止めない。
- プロファイル自動復旧の本家PRは今すぐ作らない。継続保守コストを下げる効果が明確な純粋修正だけ、個別に再検討する。
- storage mutation queueのタイムアウトは追加しない。現在の内部操作は完了callbackを通り、途中でタイムアウトして次処理を開始すると遅延完了した書き込みと競合するため、単純な安全弁は逆に整合性を下げる。

## 検証

- Node回帰テスト: 24件（今回追加分を含む）
- 全JavaScriptの構文検査
- Chromium / Firefox manifest、locale、参照ファイルの整合性
- Chromium / Firefox ZIPの許可リストと開発用ファイル混入検査
- Bash検証スクリプトの構文
- Git差分の空白エラー
